# Contaê

O Contaê é um aplicativo Android para organização e controle de finanças pessoais.

Com ele, é possível cadastrar categorias de gastos, definir limites, registrar despesas e acompanhar quanto já foi utilizado do orçamento. O aplicativo também apresenta um resumo das informações e um relatório dos gastos.

## Funcionalidades

- Login e tela inicial
- Resumo financeiro
- Cadastro de categorias
- Definição de limite por categoria
- Cadastro de despesas
- Associação de despesas às categorias
- Exclusão de categorias e despesas
- Visualização dos detalhes de categorias
- Visualização dos detalhes de despesas
- Cálculo do total gasto por categoria
- Cálculo do percentual do orçamento utilizado
- Controle do orçamento
- Relatório de gastos
- Navegação entre as telas através da barra inferior

Os dados são armazenados apenas em memória. Portanto, não é necessário configurar um banco de dados para utilizar o aplicativo.

## Tecnologias

- Android
- Jetpack Compose
- Material 3
- Navigation Compose
- Gradle
- Android Studio
