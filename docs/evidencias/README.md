# Evidências — Contaê Trabalho 3

Gravem o app real no emulador ou aparelho e adicionem os arquivos nesta pasta, ou insiram links acessíveis para os vídeos. Não usem mockups como prova de persistência.

## Roteiro recomendado

1. **CRUD de categoria:** mostrar a lista, cadastrar uma categoria de teste, editar o nome/limite, salvar e excluir.
2. **CRUD de despesa:** cadastrar uma despesa em uma categoria existente, editar a descrição ou valor, salvar e remover.
3. **Persistência (obrigatório):** cadastrar uma despesa com nome fácil de reconhecer, fechar/forçar a parada do Contaê, abrir novamente, ir à tela Despesas e mostrar o mesmo registro. Para evidenciar que é o banco e não só a navegação, encerre o processo inteiro.
4. **Detalhes por ID:** abrir uma despesa ou categoria a partir de um cartão da lista e mostrar a tela de detalhes carregada.

## Arquivos esperados

- `categoria-crud.mp4`
- `despesa-crud.mp4`
- `persistencia-fechar-reabrir.mp4`
- `categorias.png` ou `despesas.png`
- `detalhes-por-id.png`

Ao concluir, atualize o README principal com links para os arquivos. Registrem somente evidências realmente capturadas e testadas pelo trio.
